# ScholarSync SIH Prototype

A React + TypeScript + Vite prototype with student and admin demo portals. Uses synthetic data and simulated verification; it is not connected to NSP or government systems.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.

## Deploy on Vercel

Import this folder/repository as a Vite project. Set the root directory to this folder (the one containing `package.json` and `src/`), the build command to `npm run build`, and the output directory to `dist`.
